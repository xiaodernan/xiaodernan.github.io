本机行为观察站

Local behaviour observatory

用公开口令 123 进入。面板只读取当前这台浏览器的 localStorage：访问、停留、滚动、点击热区、迷失点击、焦躁连点，并据此给出下一步优化动作。

Enter with the public passcode 123. The panel reads only this browser's localStorage — visits, dwell, scroll, click zones, lost clicks, rage clicks — and derives next-step actions from them.

输入口令

Enter passcode

这是公开口令，123，任何访客都可以进入查看本机记录。它不保护隐私数据，只用于把入口与普通浏览分开。

The passcode is public: 123. Any visitor may enter and view this browser's records. It guards nothing private — it only separates the panel from ordinary browsing.

口令错误会清空输入框；连续错误不会锁死，也不会记录口令内容。

A wrong passcode clears the field. No lockout, and the passcode itself is never recorded.

口径边界：Scope: 这是纯静态站点，没有服务端数据库。以下全部读数来自当前这台浏览器的 localStorage（键名 zx-telemetry:v1），是真实的本机观察记录，不是全站全量统计；换设备、换浏览器看到的是那一台自己的数据。标记为「模拟」的样本由页面生成、仅用于演示分析逻辑，可随时排除。 This is a static site with no server database. Every reading below comes from this browser's localStorage (key zx-telemetry:v1) — a real local observation record, not a site-wide census. Another device or browser shows its own data. Samples marked “simulated” are generated by the page only to demonstrate the analysis, and can be excluded at any time.
— 真实样本与模拟样本分开计数，面板始终标明当前口径。 Real and simulated samples are counted separately; the panel always states the current scope.

近 14 天访问趋势

Visits, last 14 days

按本机日期聚合 page view；柱顶数字为当日次数。预测值由最近样本线性外推，仅作方向参考。

Page views grouped by local date; the number atop each bar is that day's count. The forecast is a linear extrapolation — direction only.

语言 / 主题 / 设备

Language / theme / device

按访问次数占比。语言取页面当时的实际语言，不取浏览器偏好。

Share of visits. Language is the page's actual state at visit time, not the browser preference.

点击热区

Click zones

只统计落在可交互元素上的点击；比例按总点击计。

Only clicks landing on interactive elements; shares of all clicks.

迷失点击热点

Lost-click hotspots

点在了不可交互的位置。它们通常意味着「这里看起来应该能点」。

Clicks on non-interactive spots — usually meaning “this looked clickable”.

会话明细（最近 12 条）

Session detail (latest 12)

一条会话 = 一次标签页生命周期；停留为各页停留之和。

One session = one tab lifetime; dwell is summed across pages.

下一步优化动作

Next optimisation actions

按当前读数触发的规则，从高到低排序；没有触发条件时也会明说。

Rules triggered by the current readings, highest priority first; if none fire, the panel says so.
